# 0001. AI 직원 전용 조직 구조와 엔진 이원화

상태: Accepted
날짜: 2026-08-17
결정자: 대표

## 맥락
사람 직원 없이 AI 직원만으로 회사를 운영하되, 추가 API 과금 없이 보유 구독(Claude Max, z.ai GLM Coding Max)만 사용해야 한다.
2026년 2월 Anthropic이 Claude 구독 OAuth 토큰을 제3자 툴에서 사용하는 것을 금지했다. 반면 z.ai Coding Plan은 API 키를 정식 발급하며 호출이 플랜 쿼터에서 차감된다.

## 결정
1. **엔진 이원화**: 실무 직원 7명은 z.ai(glm-5.3), 임원 2명(비서실장·QA총괄)은 Claude로 운영한다.
2. **Claude 접근 통로 제한**: Claude는 `claude -p` 헤드리스, Claude Agent SDK, 공식 GitHub Action 세 가지로만 호출한다. 제3자 하네스에 Claude 자격증명을 절대 주입하지 않는다.
3. **프로세스 격리**: z.ai 워커 프로세스와 Claude 임원 프로세스는 환경변수를 공유하지 않는다. 두 세계는 파일과 GitHub Issue로만 소통한다.
4. **SSOT**: 업무는 GitHub Issue, 대화는 Discord, 기억은 이 저장소의 파일.

## 근거
- 검토한 대안 A) 전부 오픈클로 + Claude 연동 → 정책 위반으로 계정 리스크. 기각.
- 검토한 대안 B) 전부 z.ai → 안전하지만 고난도 판단 품질이 떨어짐. 부분 채택(실무진).
- 검토한 대안 C) 전부 Claude → 쿼터가 며칠 만에 소진됨. 기각.
- 채택안은 비용 0을 유지하면서 판단이 필요한 지점에만 Claude를 쓴다.

## 결과
- 얻는 것: 추가 과금 없음, 계정 정지 리스크 제거, 판단 품질 확보
- 포기하는 것: Claude를 대량 병렬 실무에 투입하는 선택지
- 제약: 임원진 호출은 하루 30회 수준으로 묶인다. 회의는 비동기 문서형이 기본이 된다.
