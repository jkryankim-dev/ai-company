# 0003. 두레의 첫 업무는 Beads Sort 구글 플레이 정식 출시

상태: Accepted
날짜: 2026-08-18
결정자: 대표
대체: 0002 (사내 대시보드)

## 맥락
대표가 이미 개발을 마치고 플레이 콘솔에 올려둔 앱이 있다. 사내 대시보드를 먼저 만드는 것은 순서가 뒤바뀐 판단이었다.
현물이 있고 출시가 눈앞이면, 회사의 첫 산출물은 그것을 실제로 세상에 내보내는 일이어야 한다.

## 결정
두레의 첫 업무는 **Beads Sort(`com.jkryankim.beadssort`)의 구글 플레이 정식 출시**다.

- 제품 저장소: `C:\dev\hanoi` (Flutter, 별도 저장소)
- 회사 저장소: `jkryankim-dev/ai-company` — 이슈·의사결정·회의록만. 제품 코드는 섞지 않는다.
- 완료의 정의: 프로덕션 트랙에 심사 통과하여 스토어에 공개 노출된 상태.

## 확인된 현황 (2026-08-18 실측)
- 버전 1.0.2+3, applicationId `com.jkryankim.beadssort` (변경 불가 — 이미 업로드됨)
- 릴리즈 서명 구성 완료 (`android/key.properties` 존재)
- R8 비활성 — 축소 빌드가 실기기에서 실행 즉시 크래시하여 v1은 의도적으로 끔
- 스토어 자산 보유: 아이콘 512, 피처그래픽 1024x500, 폰 스크린샷 3, 7인치 태블릿 3
- 스토어 문구 한/영 작성됨 (`docs/store_listing.md`)
- AdMob 연동됨 (`google_mobile_ads`) — 광고 있음
- 테스트 존재: `rules_test.dart`, 골든 테스트

## 최우선 블로커
**테스트 트랙 종류 확인.** 신규 개인 개발자 계정은 프로덕션 접근 전에
비공개 테스트(Closed testing) 12명 이상 × 14일 연속이 필요하며, **내부 테스트(Internal)는 카운트되지 않는다.**
대표가 현재 "내부 테스트" 인원을 채우는 중이라면 14일 시계가 아직 시작조차 안 된 것이다.

확인 사항 두 가지 (대표만 가능):
1. 계정 유형이 개인인가 조직인가 — 조직이면 이 요건 자체가 면제
2. 현재 테스터를 모으는 트랙이 내부 테스트인가 비공개 테스트인가

이 답에 따라 출시일이 최대 2주 이상 달라진다. 다른 모든 작업보다 앞선다.

## 인력 배치
- 김기획: 아래 작업들을 반나절 단위 이슈로 분해. 트랙 확인 결과를 받기 전에도 병행 가능한 것부터.
- 이빌드: AdMob 관련 정책 대응 — 데이터 안전(Data safety) 신고 항목 정리, AD_ID 권한 확인, 광고 SDK 최신성
- 박빌드: 릴리즈 빌드 검증 — AAB 생성, 서명 확인, targetSdk 요건 충족, 실기기 설치 테스트
- 최감사: 출시 전 최종 점검. 완료 판정 기준은 "정책 항목 전수 통과 + 실기기 크래시 없음"
- 서카피: 스토어 등록정보 최종본(한/영), 짧은 설명·전체 설명 다듬기, 릴리즈 노트
- 오운영: 개인정보처리방침 호스팅 방안 정리, 콘텐츠 등급 설문 답안 초안
- 남기록: 출시 과정의 결정을 ADR로 축적
- 정지표: 출시 후 지표 수집 항목 정의 (설치, 이탈, 광고 노출)
