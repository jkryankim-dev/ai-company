## 1. 테스터 단체방 출시 안내 (리뷰 요청 1줄 포함)

### A안 — 짧은 알림형
```
Beads Sort가 정식 출시됐습니다. 비공개 테스트에 참여해 주셔서 감사합니다.

다운로드: 〔스토어 링크〕

테스트 기간 알려 주신 의견은 다음 업데이트에 반영하고 있습니다.
마음에 드셨다면 스토어에서 별점과 리뷰를 남겨 주세요 — 앱 개선에 직접 쓰입니다.
```

### B안 — 상세형
```
안녕하세요, Beads Sort가 정식 출시됐습니다. 비공개 테스트에 참여해 주신 덕분에 여기까지 왔습니다. 감사합니다.

■ 지금 받기: 〔스토어 링크〕 (무료)

■ 이 게임은
- 구슬을 색별로 옮겨 담는 편안한 퍼즐입니다
- 되돌리기 무제한, 목숨 없음, 시간 제한 없음 — 실패 부담 없이 천천히 풀 수 있습니다
- 오프라인에서도 플레이됩니다

테스트 기간에 알려주신 불편점은 다음 업데이트(v1.1) 반영 목록에 넣어 준비 중입니다.
마음에 드셨다면 스토어에서 별점과 리뷰를 남겨 주세요 — 앱 개선에 직접 쓰입니다.
```

차이: A는 단체방 특성(이미 게임을 아는 사람)상 링크·감사·리뷰만 남긴 4줄, B는 최종 버전 기능을 처음 정리해 준다. 리뷰 요청은 두 안 모두 보상·인센티브 없는 자발적 요청 1줄로 통일(전략 7항 — 인센티브 리뷰는 정책 위반). 추천 A — 테스터는 기능을 이미 알고, D+2에 v1.1 반영 목록 안내가 별도로 간다(전략 10항).

## 2. 커뮤니티 출시글

게시처: 모집글을 올렸던 〔커뮤니티 채널〕 재게시 — 신규 채널 확장 없음(전략 8항).

### A안 — 알림형 (기존 모집글 스레드 이어 올리기)
```
지난번 비공개 테스터 모집에 신청해 주신 분들 덕분에 마무리됐습니다. 이제 Beads Sort가 정식 출시됐습니다.

무료 · 안드로이드: 〔스토어 링크〕

되돌리기 무제한·목숨 없음·오프라인 가능한 구슬 정렬 퍼즐입니다. 테스트에 참여하신 분들께 감사드립니다.
```

### B안 — 소개형 (새 글로 올리기)
```
안녕하세요, 안드로이드 퍼즐 게임 Beads Sort를 출시했습니다.

구슬을 색별로 옮겨 담는 정렬 퍼즐인데, 이 게임은 규칙을 하나 바꿨습니다 — 되돌리기가 무제한이고 목숨도 시간 제한도 없습니다. 실수해도 되돌리면 되니까 하기 싫어질 때까지 천천히 풀 수 있습니다.

- 되돌리기 무제한 · 목숨 없음 · 시간 제한 없음
- 오프라인 플레이 가능
- 무료

다운로드: 〔스토어 링크〕

지난번 테스터 모집에 참여해 주신 분들께 감사드립니다.
```

차이: A는 모집글 스레드 맥락을 그대로 이어받아 짧고 감사 중심, B는 게임을 모르는 독자에게 차별화 3요소(전략 6항)를 앞세운 소개. 추천 A — 재게시 채널은 모집 반응이 검증된 곳이라 맥락 유지가 자연스럽고, 전면 소개형 콘텐츠는 D+7 후기글(전략 12항)의 몫이다.
