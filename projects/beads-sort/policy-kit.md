| 방침 문구(섹션) | 앱 실제 | 판정 |

## 3. IARC 콘텐츠 등급 설문 답안표
주의: IARC 문항 원문은 콘솔 설문 화면에만 있어 사내 실측 불가. 아래는 **주제별 답과 근거**이며
문항 수·표기는 콘솔 화면과 어긋날 수 있다(사규 12조: 외부 요건은 변동). 대표는 화면 항목에 이 표의
주제를 대응해 입력한다.

| 주제 | 답 | 근거 |
|---|---|---|
| 폭력(현실/만화/환상 구분 무관) | 해당 없음 | 물 정렬 퍼즐, 폭력 표현 없음(context.md:15) |
| 성적 콘텐츠·노출 | 해당 없음 | 동일 |
| 욕설·공격적 언어 | 해당 없음 | 텍스트는 퍼즐 UI 최소 범위 |
| 약물·음주·흡연 | 해당 없음 | 동일 |
| 공포·잔혹 표현 | 해당 없음 | 동일 |
| 도박·도박 시뮬레이션 | **확인 필요** | 코인 경제 존재(context.md:16). 코인이 확률형 요소(뽑기·룰렛)에 쓰이면 답이 달라짐. 힌트·이어하기 재화만이면 "아니오" — APP_REPO·스토어 등록문서 확인 후 확정 |
| 사용자 콘텐츠 공유(UGC)·채팅·멀티플레이 | 해당 없음 | 의존성에 소셜·멀티플레이 SDK 없음(context.md:17) |
| 위치 공유·사용자 간 통신 | 해당 없음 | 개발자 직접 수집 없음(방침 §1과 대조 일치) |
| 범죄 조장·통제 물품 | 해당 없음 | 해당 기능 없음 |
| 인앱 결제(아동 보호·Family 표기 연동) | **확인 필요** | 코인 유료 판매 여부 미확인 — context.md에 인앱결제 미기재, 확인 경로는 콘솔·APP_REPO |

예상 등급: 확인 필요 2건이 모두 "아니오"로 확정되면 **전연령(Everyone)**.
