# 테스터 모집 킷 (대표 발송용)

독자: 대표. 아래 문구는 복사해 그대로 보내는 최종본이다. 직원은 발송하지 않는다 (사규 6조).
작성: 서카피 / 2026-08-18

## 보내기 전 딱 하나 고칠 것
모든 문구의 **〔옵트인 링크〕**를 플레이 콘솔의 비공개 테스트 트랙 > 테스터 화면에 표시된 링크로 교체한다. 그 외에는 편집 없이 그대로 보낸다.

기준 수치 (context.md, 플레이북):
- 목표 옵트인 **15~16명** (12명은 최소값, 이탈 대비 여유)
- 12명 옵트인이 채워진 날 = **14일 시계 시작일**. 리마인드 메시지의 "1일차"는 이 날을 뜻한다.

## 1. 지인용 짧은 문구 (카톡/DM)

```
안녕하세요, 제가 만든 안드로이드 게임 'Beads Sort'가 구글 플레이 출시 전 비공개 테스트 단계에 들어갔어요. 테스터가 필요해서 연락드립니다. 등록은 5분이면 끝나고, 게임은 되돌리기 무제한·시간 제한 없는 편안한 구슬 정렬 퍼즐이에요.

■ 테스터 등록 3단계 (안드로이드 폰)
1. 플레이 스토어 앱 오른쪽 위 프로필 아이콘 → 지금 로그인된 구글 계정을 확인하세요. 이 계정으로 테스터 등록이 됩니다.
2. 아래 링크를 복사해서 크롬이나 삼성 인터넷 브라우저 주소창에 붙여넣어 여세요. 브라우저도 같은 구글 계정으로 로그인된 상태여야 해요.
   〔옵트인 링크〕
3. 페이지의 '테스터가 되기' 버튼을 누르세요. 그다음 플레이 스토어에서 'Beads Sort'를 검색해 설치하면 끝입니다.

■ 자주 생기는 일
- 버튼을 눌렀는데도 스토어에 바로 안 보일 수 있어요 → 반영에 시간이 걸립니다. 조금 뒤 스토어를 껐다 켜고 다시 검색해 보세요.
- 설치는 했는데 앱을 안 열었어요 → 테스트 기록은 앱을 실제로 열어야 쌓입니다. 설치 후 꼭 한 번 열어 주세요.

2주 정도 틈날 때 가끔씩만 켜 주시면 되고, 불편한 점을 한 줄이라도 알려주시면 다음 버전에 반영할게요. 미리 감사드립니다!
안드로이드 폰 쓰는 다른 지인분께 이 메시지를 그대로 넘겨주셔도 좋아요.
```

게시판 홍보 규칙이 있는 커뮤니티는 해당 규칙에 맞춘다. 아래는 본문 그대로.

**제목:**

```
[테스터 모집] 구슬 정렬 퍼즐 'Beads Sort' 안드로이드 비공개 테스터를 찾습니다 (2주, 등록 5분)
```

**본문:**

```
안녕하세요, 개인 개발자입니다. 구글 플레이 정식 출시를 앞두고 안드로이드 비공개 테스트 테스터를 모집합니다.

■ 게임 소개
'Beads Sort'는 같은 색 구슬을 핀에 꿰어 정리하는 정렬 퍼즐입니다.
- 되돌리기 무제한, 목숨·시간 제한 없음
- 300개 레벨, 모두 풀 수 있음이 검증됨
- 난이도를 감이 아니라 실제 시뮬레이션으로 측정한 통과율로 배치 (어려운 판은 '통과율 18%'처럼 숫자로 표시)
- 오프라인 플레이 가능

■ 테스터가 할 일
- 아래 3단계로 테스터 등록 후 설치
- 2주 동안 주 3~4회(이틀에 한 번 정도) 게임을 열어 주시면 됩니다. 매일은 필요 없습니다.
- 불편한 점·버그를 발견하면 댓글이나 메일로 알려 주세요. 다음 버전에 반영합니다.

■ 테스터 등록 3단계 (안드로이드)
1. 플레이 스토어 앱 오른쪽 위 프로필 아이콘 → 지금 로그인된 구글 계정을 확인하세요. 이 계정으로 테스터 등록이 됩니다.
2. 아래 링크를 복사해서 크롬이나 삼성 인터넷 브라우저 주소창에 붙여넣어 여세요. 브라우저도 같은 구글 계정으로 로그인된 상태여야 합니다.
   〔옵트인 링크〕
3. 페이지의 '테스터가 되기' 버튼을 누르세요. 그다음 플레이 스토어에서 'Beads Sort'를 검색해 설치하면 끝입니다.

■ 유의 사항
- 등록 후 스토어에 앱이 바로 안 보일 수 있습니다. 반영에 시간이 걸리니 조금 뒤 스토어를 껐다 켜고 다시 검색해 주세요.
- 설치만 하고 실행하지 않으면 테스트 기록이 쌓이지 않습니다. 설치 후 꼭 한 번 실행해 주세요.

- 어떤 기종·안드로이드 버전이든 참여 가능합니다.
```

## 3. 옵트인 3단계 상세 안내 (문의 온 사람에게 보내는 답장용)

"등록이 안 돼요"라는 연락을 받았을 때 해당 단계를 그대로 붙여넣는다.

### 1단계 — 스토어 로그인 계정 확인
- 할 일: 플레이 스토어 앱 → 오른쪽 위 프로필 아이콘 → 로그인된 구글 계정 확인. 계정이 여러 개면 '평소 앱을 설치할 때 쓰는 계정'을 기억해 둔다.
- 왜: 옵트인은 계정 단위로 등록된다. 이 계정과 다른 계정으로 링크를 열면 등록이 엉뚱한 계정으로 간다.
- 실패 증상: 3단계까지 마쳤는데 플레이 스토어에서 앱이 검색되지 않거나 설치 목록에 나타나지 않음.
- 해결: 스토어 프로필 아이콘 → 계정 전환 → 등록할 때 쓴 계정으로 바꾸고 다시 검색.

### 2단계 — 링크를 웹 브라우저로 열기
- 할 일: 링크를 길게 눌러 복사 → 크롬/삼성 인터넷 주소창에 붙여넣기. 브라우저 오른쪽 위의 구글 계정이 1단계 계정과 같은지 확인.
- 실패 증상: 메신저 앱 안에서 바로 열면 페이지가 다르게 보이거나 버튼이 안 보임. 브라우저가 다른 구글 계정으로 로그인 중이면 그 계정으로 등록됨.
- 해결: 브라우저에서 구글 계정을 전환하거나, 시크릿 모드에서 1단계 계정으로 로그인한 뒤 링크를 다시 열기.

### 3단계 — '테스터가 되기' 버튼 클릭
- 할 일: 페이지의 '테스터가 되기' 클릭 → '테스터가 되셨습니다' 확인 → 플레이 스토어에서 'Beads Sort' 검색 → 설치 → 실행.
- 실패 증상 1: 버튼을 누르지 않고 페이지를 닫음 → 등록이 안 된다 (가장 흔한 이탈 원인).
- 실패 증상 2: 등록했는데 스토어에 바로 안 뜸 → 반영 지연. 시간을 두고 스토어 앱을 재시작한 뒤 다시 검색.
- 실패 증상 3: 페이지에 '테스트가 종료되었습니다' 같은 안내가 보임 → 링크·트랙 문제 가능성. 대표에게 알려 달라고 전달.

## 4. 리마인드 메시지 3종 (테스터 단체방 또는 개별 DM)

기준: **12명 옵트인 완료일 = 1일차** (플레이북 — 14일 시계는 12명이 옵트인한 시점부터 시작). 그 전에 보내는 조기 독려는 1번 문구를 변형해 쓴다. 링크는 1번에만 들어 있으니 그대로 유지.

### 3일차

```
Beads Sort 테스트 3일째입니다. 참여해 주셔서 감사합니다.

아직 테스터 등록을 마치지 않으신 분은 이 3단계만 끝내면 바로 참여됩니다 (5분).
1. 플레이 스토어 오른쪽 위 프로필에서 로그인된 구글 계정 확인
2. 링크를 크롬 등 웹 브라우저로 열기 — 〔옵트인 링크〕
3. '테스터가 되기' 클릭 후 플레이 스토어에서 'Beads Sort' 설치

설치는 하셨는데 아직 실행 안 해 보신 분은 오늘 한 번만 열어 주세요. 테스트 기록은 앱을 실제로 열어야 쌓입니다.
켜 보시고 불편한 점이 있으면 무엇이든 한 줄 회신해 주세요. 다음 버전에 반영하겠습니다.
```

### 7일차

```
Beads Sort 테스트가 절반 지났습니다 (7일째). 여기까지 함께해 주셔서 감사합니다.

2주 동안 주 3~4회만 열어 주시면 테스트 기록이 충분히 쌓입니다. 최근에 못 켜신 분은 오늘 한 판 어떨까요?

요즘 몇 판째인지, 어느 판에서 막히셨는지 한 줄 남겨주시면 난이도 조절에 직접 반영됩니다. 힌트나 빈 핀 같은 도움 요소에 대한 생각도 환영입니다.
```

### 12일차

```
Beads Sort 테스트 12일째입니다. 14일 요건이 거의 다 찼습니다. 마지막까지 함께해 주셔서 감사합니다.

테스트 판정은 '2주 동안 꾸준히 열었는가'를 봅니다. 이번 주에 아직 못 켜신 분은 오늘이나 내일 중 한 번만이라도 실행해 주시면 큰 도움이 됩니다.

테스트 기간이 끝나도 설치한 게임은 그대로 즐기실 수 있고, 정식 출시 소식은 테스터분들께 가장 먼저 드리겠습니다. 아쉬웠던 점이 있다면 지금 편하게 남겨 주세요.
```

## 5. 대표 운영 메모 (발송용 아님)

- 발송 채널별 옵트인 수를 그날그날 `projects/beads-sort/test-journal.md`에 기록한다. 프로덕션 신청서에 '테스터를 어떻게 모집했는가' 질문이 있다 (플레이북).
- 12명이 채워진 날짜·시각을 반드시 기록한다. 14일 시계 시작일이 되고, 최단 출시일 계산의 기준이다.
- 목표는 12명이 아니라 15~16명 옵트인이다 (플레이북 — 이탈 대비 여유분).
- 테스터의 기기·안드로이드 버전이 하나로 몰리면 인위적으로 보여 거절 사유가 될 수 있다. 같은 기종만 모이면 다른 기종의 지인을 추가로 구한다 (플레이북 거절 사유 5번).
