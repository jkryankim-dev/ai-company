# 큐 #7 상신 첨부용 — 주간 호출량 증분 산출 노트

작성: 정지표 2026-10-09. `org/proposals.md` 큐 #19 채택(2026-10-09 종합, 판정 정본은 회의록) 이행
산출물. 용도: 큐 #7(구현 세션 증설, 보류·대표 상정) 대표 상신 시 종합자가 인용하는 수치 근거.

## 결론 (숫자)
- 구현 세션 **1회/주 추가 = 전체 +9 호출/주, 직원당 +1 호출/주**.
- 큐 #7 병합 안(2026-09-28-allhands.md:71 "dev_1 주 2회") 기준: **전체 +18 호출/주, 직원당 +2/주**.
- 현행 회의 세션 기준선 63 호출/주 대비 증가율: 1회 추가 +14.3%, 주 2회 +28.6%.
- z.ai 주간 한도 대비 비율 환산은 **불가** — 한도 값 미입력(2026-10-09 기준 31일, org/console-input.md
  '붙여넣는 곳'). 값 도착 시 weekly.json quota.usage_pct에 병기한다(마감 규칙).

## 산식
- 세션 1회 종료 시 직원 9인이 각 1호출 소진 → 1세션 = 9 호출(패턴 검증 아래).
- 증분 = 추가 세션 수 × 9 호출/주. 직원당 = 추가 세션 수 × 1.
- 기준선 = 현행 주간 세션 7회(평일 09:00 스탠드업 5 + 월 10:00 전사회의 1 + 금 17:00 회고 1) × 9 = 63.
