# 주간 마찰 보고 — 이빌드 (2026-10-30)

지난회 보고(2026-10-23) 3건(시한 이월 무비용·선언→접수 공백·개설 경합) 및 10/16 마찰 1(배포 관문
무상한)과의 중복 회피: 마찰 1은 '판정 집행 주체 단일 실패점', 마찰 2는 배포 관문의 '무효력 실측'

## 마찰 1. 판정 채널이 당일 종합자 1개뿐이라 종합자 장애 3일이 제안 큐 전체를 정지시켰다 — '판정 시 확정' 분류 안건에는 탈출로가 없다

**무슨 일이 있었나**
- 10/26 접수한 내 안건 3건(#43 main 병합 2트랙·#44 만료 후 절·#45 dry-run) 전부 판정 기한
  10/28 경과 후에도 무판정. 원인은 종합 세션의 401 OAuth 실패로 판정 절차 미실행 —
  10/27·28·29 3일 연속(org/proposals.md #41 판정칸 기재, 각일 standup.md 종합절 원문).
- #45는 행내 분류 '회사 자체 가능'이라 규칙 3으로 10/29 자체 채택해 이행했다. 같은 날 접수된
  #43·#44는 분류가 '판정 시 확정'이라 자체 채택 불가 — 지금도 판정칸 공란(proposals.md:70-71,
  금일 세션 재확인). 48시간 상한(규칙 2) 경과 사실 자체는 어디에도 강제 상정되지 않는다.

**왜 막혔나**
- 판정의 집행 주체가 '당일 종합자' 단일 경로라 종합자 장애가 곧 판정 파이프라인 정지다. 401
  재인증은 대표 전용이라 회사 측에는 복구 수단이 없는데, 정지 상태를 알리는 장치도 없다.
- 규칙 3의 자체 채택은 '회사 자체 가능' 분류일 때만 작동한다. '판정 시 확정' 분류는 무판정이
  몇 달 계속돼도 상태 전이 규칙이 없다 — 지난주 마찰 1(이월 무비용)과 같은 뿌리가 집행 주체
  장애 형태로 재발한 것이다.

**무엇을 바꾸면 되나**
- 종합자 판정 불능(401 등)이 N일 지속 시 '판정 시 확정' 안건도 분류 재심의 대상에 오르는
  규칙 3 확장 — 재심의에서 '대표 판단 필요'로 남을지 '사전 위임 가능'으로 바뀔지 결정한다.
- 판정 정지 상태(무판정 경과 일수·종합 오류)를 standup digest에 자동 노출(ADR 0015와 같은
  수정 경로, 회사 자체 가능) — 상한 경과가 상태값으로 보이면 3일 침묵이 방치되지 않는다.

## 마찰 3. dev 부서 활성 몫이 전부 대표 전용 전제 자산 뒤에 있어 이번 주에도 실질 코드 커밋 0건이었다 — 대기 중 대체 배정 규칙이 없다

**무슨 일이 있었나**
- 이번 주 내 산출은 dry-run 문서 1건·dev 섹션 파일 개설뿐, 제품·스크립트 코드 커밋 0건
  (dev_1 최신 코드 커밋은 10/19 88c03c6 그대로). 활성 이슈 #8은 `!지시`·재기동이 대표 전용,
  #5·#6은 APP_REPO(.env:19 빈값, 10/30 실측 — 박빌드 서브섹션)·gh 쓰기 토큰(approvals#11,
  9/21 상신 39일) 대기라 착수 불가. 배정표에 자체 실행 가능 dev 행이 없다.
- approvals#2(APP_REPO, 8/19 상신)는 10/30 기준 72일 대기 중이다.

**왜 막히나**
- 자산(경로·토큰·재기동 권한) 확보가 착수의 선행 조건인데 확보 시점이 전부 대표 재량이고,
  대기 기간 중 dev에게 줄 대체 몫을 만드는 규칙이 없다. 이슈는 '자산 도착 후 시작' 구조로만
  작성돼 있어 대기가 길어질수록 dev 가동률이 0으로 수렴한다.
- 지난 주 같은 상태(주간결과 미완 4항)가 이번 주에도 그대로 — 주간 단위로 같은 보고가
  반복되는 것 자체가 구조 문제의 증거다.

**무엇을 바꾸면 되나**
- 대표 전용 자산 의존 이슈를 배정할 때 '자산 대기 중 수행 가능한 선행·병행 몫'(큐 #41 PR 발행
  초안 방식)을 지시서 필수 행으로 붙이는 규칙 — 착수 가능한 몫을 항상 1개 이상 동반하게 한다.
- 스프린트 배정에 dev 자체 실행 행 상시 1개 이상 유지(회사 자체 가능 범위의 사내 스크립트·
  기록 관리 개선 포함). 본 건은 차기 세션 큐 접수 후보로 제안한다.
