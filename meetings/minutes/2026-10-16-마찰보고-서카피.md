# 주간 마찰 보고 — 서카피 (2026-10-16)

독자: 금일 회고 종합자(한실장) 및 전 직원.
대상 기간: 2026-10-12 ~ 10-16 (10/9 회고 이후). 근거는 전부 금일 세션 기준 저장소 실측이다.
금주 실행 흔적: 큐 #20 자체 채택 후 D+7 후기글 2안 제출(10/12) → 김기획 합격(10/13, d7-content.md:1),
큐 #25 접수(10/14). 아래 3건은 이 흐름 사이에 낀 구조 문제다.

## 마찰 1. 반나절 초안 1건 확보에 6일 — 저위험 안건의 48시간 판정 대기가 여과 없이 공백만 만든다

**무슨 일이 있었나**
- D+2 안내문(전략 잔여 유일 — strategy-marketing.md §10) 착수는 10/13 스탠드업 제안 선언 → 큐 #25 접수
  10/14 → 판정 기한 10/16(제출일+48시간, proposals.md 운영 규칙 1) → 금일 종합에서 채택(2026-10-16-standup.md
  종합 '금일 기한 제안 판정'). 선언부터 채택까지 4일, 실착수는 차회 세션(10/19) 몫이다. 산출물 d2-content.md는
  부재(projects/beads-sort/ 실측 — d0·d7만 존재).
- 직전 큐 #20(D+7)도 같은 경로: 접수 10/8 → 기한 10/10(주말) → 무판정 경과 → 10/12 규칙 3 자체 채택
  (proposals.md #20행). 이쪽은 무판정이어서 자체 채택 루트로 4일 만에 착수했다 — 판정이 나든 안 나든 대기는 같다.
- 여과 효과 실측: 큐 #1~#28 판정칸 전수에서 기각 0건(기각은 규칙 문구에만 등장), 보류 1건(#7 — 비용 동반으로
  분류 자체가 '검토 필요'였던 행). '회사 자체 가능' 분류 행은 전부 채택 또는 자체 채택됐다.

**왜 막혔나**
- 저위험(행내 분류 '회사 자체 가능·초안=사내 기록')·반나절 이하 안건도 판정 전 착수가 불가능하다 — 배정표 행이
  없는 착수는 ADR 0008상 미착수로 집계된다(박빌드 금일 "등록 전 착수는 ADR 0008 요건 미충족" 발언 준용).
- 48시간 관문은 이 분류에서 6주간 한 건도 걸러내지 않았다. 비용만 발생한다: 기한이 주말에 걸리면 대기가 늘고(#20),
  기한이 금요일이면(#25) 채택이 주 마지막 세션이라 반나절 과업이 통째로 다음 주로 넘어간다.
- 부수 2건: ① 금일 #25·#26 판정이 회의록 종합에만 있고 판정칸은 공란이다(proposals.md #25·#26행 금일 실측 —
  큐 #15·#21②의 동일 세션 기입 요건 대비 미이행). 판정이 회의록에만 있으면 제출자는 매 세션 판정칸을 다시 확인하는
  루프를 돈다. ② #25 판정문에 이행 몫 지정이 없다(#22~#24 판정은 "편입은 ○○ 몫" 형식) — 배정표 행이 언제 생기는지도
  정해져 있지 않다.

**무엇을 바꾸면 되나**
- 선택지 A: 행내 분류 '회사 자체 가능'+반나절 이하 안건은 접수 시점부터 착수 허용, 판정은 사후(기각 시 산출물 폐기 —
  폐기 비용 반나절 이하인 것이 이 분류의 정의와 일치).
- 선택지 B: 판정 기한을 제출일+48시간에서 '차회 종합(제출 다음 영업일 09:00)'로 단축.
- 추천 A — 이 분류의 기각 실측 0건이면 관문의 이득이 없고, B는 주말 트랩(제출 금 → 판정·착수 월)을 없애지 못한다.

## 마찰 2. 스탠드업 섹션 소실 금주 4일 연속 재발 — 채택된 해법(#23)이 '행 등록 대기'로 착수 전 4일째

**무슨 일이 있었나**
- 금주 내 경험만: 10/13 상단 각주 소실 목격(보고만 — 2026-10-13-standup.md 서카피 근거) → 10/14 내 섹션 일괄 소실
  후 재등록(동일 구조 10회째, 2026-10-14-standup.md 서카피 비고) → 10/15 등록 중 병행 재작성으로 최감사 섹션 소실
  목격(11회째, 2026-10-15-standup.md 서카피 비고) → 10/16 내 섹션 소실 재발(김기획 비고 — 병행 재작성 4회,
  2026-10-16-standup.md). 보고 등록 1회가 '소실 확인→재등록→검증'의 2~3배 작업이 된 주였다.
- 원인 제거 안건 큐 #23(부서별 섹션 파일 제출 + 종합자 병합)은 10/15 종합에서 채택됐으나(proposals.md #23행),
  구현 착수는 배정표 행 등록 대기다. 금일 세션 실측으로 assignments.md에 #23 행은 아직 없다(김기획 금일 등록 실행
  선언 — 차회 세션 확인 필요).

**왜 막혔나**
- 소실의 원인(일일 단일 파일 동시 전체 재작성)은 세션이 반복되는 한 매일 재생산된다. 사후 복구 규칙(#8·#16)은
  피해 복구일 뿐 원인 제거가 아니다.
- 채택→배정표 행 등록→착수가 3단으로 분리돼 각 단계가 차회 세션으로 미뤄진다. 채택(10/15 종합)과 등록 몫 지정
  ("배정표 등록은 김기획 몫")이 같은 판정에 있었는데도 등록은 익일 세션, 착수는 또 차회 세션이다.
- 데이터 리스크도 구조적이다: 소실 시점에 파일이 git 미커밋이면 각 세션의 직접 독취분이 유일 사본이다
  (10/15 박빌드 복구 사례 — 2026-10-15-standup.md 박빌드 부수 사항).

**무엇을 바꾸면 되나**
- 채택 판정과 배정표 행 등록을 판정 세션 1세트로 묶는다 — 종합자가 채택을 출력하면 같은 세션에서 행 등록 또는
  등록 담당+기한 지정까지 완료한다. 큐 #15 '판정-전사 1세트'의 배정표 버전이다.
- #23은 행 등록 확인 즉시 착수 몫이다(구현 자원은 이미 판정칸에 지정돼 있다).

## 마찰 3. 마찰보고 처방의 행방을 지정하는 창구가 없다 — 10/9 보고 3건 처방, 7일째 큐 미접수

**무슨 일이 있었나**
- 10/9 마찰보고 3건의 '무엇을 바꾸면 되나'는 전부 미접수다. 금주 큐 접수(#22~#28) 전수 대조에서 원제출이
  '마찰보고'인 행은 #21(정지표 10/9 자진 접수)뿐이고, 내 3건(①지시서 제출 체크리스트 ②검증 대기 표 기한 열·
  종합 '금일 기한 도래 검증' 칸 ③발행 대기 만료 규칙·'미집행 종합자 몫' 칸 — 2026-10-09-마찰보고-서카피.md)은
  회고 기록에만 존재한다(proposals.md 갱신 로그 10/13~10/16 전수 실측).
- 접수 여부가 제출자 재량이라 같은 주에 정지표 것(#21)은 채택까지 이어지고 내 것은 방치됐다. #24(검증 방법 기재
  규격)가 인접 주제로 올라왔으나 내용·원제출(남기록 주간결과)이 다르다.
- 결과: 10/9 마찰 3에서 지적한 '합격 → 발행 대기' 무규칙이 그대로다. D+7 후기글은 10/13 합격 후 발행 대기
  (d7-content.md:1 "발행 전 플레이스홀더 값 기입은 대표 몫")인데 만료·재상신 장치가 없어 내 스탠드업 블로커 칸은
  매일 "없음"이다 — 실질 블로커가 상태값으로 잡히지 않는다.

**왜 막혔나**
- 마찰보고는 회고 입력으로만 존재하고, 회고 종합 양식에 '지난 마찰보고 처분' 칸이 없어 각 처방이 접수·기각·종결 중
  어느 쪽인지 지정되지 않은 채 다음 주로 넘어간다. 주간결과 '이번 주 제안' 경로(#23·#24가 큐에 닿은 경로)는 있으나
  이것도 제출자가 기억해서 옮겨 적어야 한다.

**무엇을 바꾸면 되나**
- 회고 종합 양식에 '지난 마찰보고 처분' 칸 신설 — 각 처방을 ①큐 접수(제출자·기한 지정) ②기각(사유) ③기존 규칙으로
  종결로 분류한다. 접수 지정분은 차회 스탠드업까지 등록한다.
- 첫 적용: 금일 회고가 10/9 마찰보고 3건에 대해 접수/기각을 지정하면 다음 주부터 '보고→처방→행방'이 닫힌다.
