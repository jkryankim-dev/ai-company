# 주간 마찰 보고 — 오운영 (2026-09-18)

대상 기간: 2026-09-15 ~ 09-18. 근거는 전부 금일 실측이며 각 항목에 출처를 붙였다.

## 마찰 1. 일지가 매일 '무변화 관측'의 기록이 되었다 — 무변화일 때 줄이거나 자동화하는 규칙이 없다

**무슨 일이 있었나**
- 이번 주 4일(9/15~9/18) 전부 같은 실측 3종(inbox/pending 파일 목록, git log 최종 커밋, context.md:14 빌드 번호)을 하고 같은 결과("없음", "—")를 하루 1행씩 기입했다(test-journal.md:43-46, 비고 4건).
- 일지의 실질 목적인 "옵트인 현황 변화" 칸은 8/20 이후 전부 "—"다. 입력 창구 console-input.md는 9/8 신설 후 10일째 비어 있다(console-input.md:21 금일 재확인). 최단 신청 가능일 "2026-09-01 전후"(context.md:7, tester-tracker.md:10)를 17일 지났는데 시계 종료 판정 재료도 없다. approvals #1(해당 콘솔값 상신)은 표 기준 29일 무회신(approvals.md:19).

**왜 막혔나**
- 기록 규칙이 "하루 1행"을 무조건으로 요구하고(test-journal.md:7) 무변화 연속일에 대한 축소·생략 조항이 없다. 입력 원천이 마른 상태에서 추가되는 행은 관측값이 아니라 관측 행위의 증명이다.
- 매일 반복하는 실측 3종은 셸 스크립트 1개로 행 생성이 가능함에도 자동화 후보 등록 경로가 없다. 이슈 생성은 gh 부재로 막혀 있고, 파일 접수 가능 여부는 approvals #8(22일 무회신)에 계류 중이다.

**무엇을 바꾸면 되나**
- test-journal.md 기록 규칙에 "콘솔값 무입력·보고 문제 없음이 N일 연속이면 그 구간은 주 1행으로 묶어 기입" 조항을 추가한다(기록 관리 사항 — approvals.md:9 선례, 별도 승인 불요).
- 일일 실측 3종의 스크립트화를 이번 회고 안건으로 올린다. 완료 조건(스크립트가 일지 행 양식을 표준출력으로 내는 것)과 검증 방법(출력과 수동 실측 대조)을 명시하고, gh 확보 전에는 issues-draft.md 방식의 파일 접수로 둔다.

## 마찰 2. ADR 0007 재평가를 당번마다 개별 수행했다 — 같은 결론을 여러 번 유도하는 구조

**무슨 일이 있었나**
- 9/11 한실장 지시("각 항목 6조 해당 여부 재평가")에 따라 박빌드가 9/16 #2를, 내가 9/17 #1을 각각 재평가했다(approvals.md 9/16·9/17 갱신). 두 결론의 구조는 동일했다: 6조 비해당 + 추천안 실행 주체가 대표뿐 → 대기 유지.
- 9/17 종합은 "나머지 5건도 같은 결론일 가능성이 높으니 표준 판정 채택을 회의 안건으로" 지적했다(approvals.md:69-70, 2026-09-17-standup.md:112). 방치 시 같은 서술을 5번 더 반복한다.

**왜 막혔나**
- 재평가 지시가 '당번별 개별 수행'으로 내려왔고, 판정 요소(6조 해당 여부 / 실행 주체 / 결론)를 칸으로 가진 공통 양식이 없어 각자 서술문으로 썼다. 첫 사례(#2)에서 동일 구조가 확인된 시점에 "이후 동일 구조는 생략" 규칙을 만드는 단계가 프로세스에 없었다.

**무엇을 바꾸면 되나**
- approvals.md 표에 재평가 결과 칼럼(6조 해당 / 실행 주체 / 결론)을 양식으로 추가하고, 동일 구조 2건(9/16·9/17 확정)을 근거로 남은 5건을 일괄 적용해 회의에 승인을 요청한다. 개별 서술 재작업 5건이 표 5칸 채우기로 줄어든다.

## 마찰 3. 대기 일수 정본 갱신이 이번 주에도 하루 비었다 — 9/11 마찰 3 재발

**무슨 일이 있었나**
- 규칙은 "매 스탠드업 종합 시점에 종합자가 갱신"(approvals.md:14-15)이지만 9/16 스탠드업 종합은 표를 갱신하지 않았다. 금일 실측 기준 9/16분 갱신은 박빌드의 #2 재평가 기록뿐이고 일수는 9/15치 그대로다.
- 내 9/16 보고와 일지 비고는 "표 기준 27일(9/15 갱신, 9/16은 일수 미변경)"이라는 단서를 달 수밖에 없었다(test-journal.md:53). 9/17 종합이 +2일로 한꺼번에 반영했다(approvals.md:67-68). 9/11 마찰 3에서 제안한 "어제 갱신됐는가 1줄 대조" 절차는 채택되지 않았고 같은 마찰이 재발했다.

**왜 막혔나**
- 갱신 책임을 종합자 개인의 세션에만 걸어두고 갱신 여부를 대조하는 검사 장치가 없다 — 9/11 마찰 3과 동일 원인. 원인을 고치지 않았으니 재발은 예정된 결과다.

**무엇을 바꾸면 되나**
- 종합자 갱신 안은 검사 장치 없이는 재발이 보장되는 구조다. 남기록이 상정해 둔 ADR 0010(대기 칼럼 폐지 — 최초 상신일만 두고 일수는 인용 시점에 계산, 초안 커밋 5d5b0ad)을 이번 회의에서 판정해 채택한다. 9/11 같은 제안이 '새 결정 필요'로 보류됐으니 이번에는 채택으로 종결한다.
