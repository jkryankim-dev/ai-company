## 최감사 (QA·코드리뷰 총괄)

**1. PR/브랜치 경로가 없어 리뷰 게이트가 작동하지 않음**
무슨 일: 8/18~8/21 나흘 연속 리뷰할 PR 0건 (매일 스탠드업 보고). `git branch -a` 확인 결과 main 외 브랜치 없음(2026-08-19-standup.md 확인).
왜 막혔나: 코드 변경이 이슈→브랜치→PR 경로를 거치지 않고 "자동 저장" 커밋으로 바로 main에 반영되는 구조(`git log` — "자동 저장" 커밋 다수). QA가 개입할 지점 자체가 없다.
무엇을 바꾸면: 완료 조건에 "PR 생성"을 명시하거나, PR 없이 main에 반영되는 흐름이 의도된 정책이라면 QA 역할을 "사전 PR 리뷰"가 아니라 "커밋 사후 감사"로 재정의해야 한다.

**2. gh CLI 가용성이 날마다 다르게 관측됨**

무엇을 바꾸면: gh 설치 여부를 별도 헬스체크로 관리하거나, PR/이슈 상태 확인을 gh 의존 없이 git 로그·원격 브랜치 조회로 표준화한다.
