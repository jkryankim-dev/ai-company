## 마찰 1
**무슨 일**: 9/21 `org/assignments.md`에 approvals#5·#8이 이미 "완료"로 기재됐고, 나는 9/22에야 이를 발견해 재검증에 착수했다. QA 판정(9/24)까지 사흘간 판정 없이 "완료"로 읽히는 공백 상태가 존재했다.
**왜 막혔나**: ADR 0006은 "검증 판정의 정본은 산출물 최상단 1행"이라 규정하지만, ADR 0011(자체진행 항목)은 제출자가 배정표에 곧바로 "완료"라고 적도록 허용한다. 두 규정이 결합하면 배정표상 "완료" 표기와 실제 QA 판정 사이에 시차가 생긴다.
**무엇을 바꾸면**: 자체진행 항목은 제출 시 상태를 "완료"가 아니라 "QA 대기"로 적고, 최감사 판정 후에만 "완료"로 전환하도록 배정표 기재 규칙을 명시한다.

## 마찰 2
**무슨 일**: approvals#3(gh CLI 설치) 완료 근거인 `gh --version`을 내 세션에서 그대로 실행하니 9/23 `command not found`였다. 원인 확인에 하루가 걸려 판정이 보류됐다(9/24 PATH 지정 재현으로 통과 전환).
**왜 막혔나**: 사규 4조는 "명령이 통과한 로그"만 완료 증명으로 요구할 뿐, 그 로그가 검증자의 독립 세션에서도 재현 가능해야 한다는 기준이 없다. 설치류 증거가 실행자 개인 셸(로그인 셸 PATH)에 묶여 있었다.
**무엇을 바꾸면**: 환경 설치·설정 완료 보고는 절대경로 또는 PATH 지정 실행 커맨드를 증거에 함께 적도록 사규 4조에 추가한다.

## 마찰 3
**무슨 일**: approvals#3·#5·#8은 설치 승인·종료 판정·이슈 접수처럼 단일 산출물 파일이 없는 항목이라, ADR 0006이 요구하는 "산출물 파일 최상단 1행"을 적을 곳이 없어 `qa-log.md`를 즉석에서 만들어 대체했다.
**왜 막혔나**: ADR 0006은 검증 대상이 항상 "산출물 파일"을 갖는다고 전제하고 있어, 파일로 귀결되지 않는 절차성/승인성 이슈를 다루는 규정이 없다.
**무엇을 바꾸면**: ADR 0006에 "산출물 파일이 없는 항목은 QA 지정 로그 파일을 정본으로 한다"는 예외 조항을 추가한다.

향후 QA 세션에서 참고할 수 있도록 위 3건을 메모리에 저장했다 (`qa_process_gaps_2026w4.md`).

- 막혔나: ADR 0008·0009는 착수 판정 기준일 뿐, 제안→배정 전환의 소관·시한은 어느 문서에도 없다. approvals.md는 대표 회신 큐라 이 사안이 들어가지 못한다.
- 바꾸면: assignments.md에 '제안 접수' 절 신설(검증 대기 절과 동일 구조), 종합자는 24시간 내 채택/기각, 채택 시 배정행 전환.

**마찰 2. GitHub 이슈는 정본인데 쓰기가 막혀 파일로 이중화됐다**
- 있었나: 이슈 8개 전부 `담당:없음`(매일 현황 블록 실측), 실제 담당은 assignments.md에만. gh는 읽기도 인증 요구(9/22 실측)해 #8 본문을 무인증 REST로 우회 열람. close·생성은 approvals#11 대기로 #1~#4가 종료 승인 후에도 열려 있다.
- 막혔나: 사규 2조가 이슈를 일의 존재 장소로 규정할 때 회사에 쓰기 권한이 없다는 전제가 빠졌다. 두 정본 대조 비용이 매일 전원에게 발생한다.
- 바꾸면: 토큰 공급 전 "파일이 정본, GitHub는 읽기 전용 미러"를 ADR로 명문화 + 사규 2조 예외 조항. 현황 블록도 GitHub 덤프 대신 배정 정본 요약으로.

**마찰 3. 완료 조건 결측이 착수 시점에야 발견된다**
- 있었나: #8 하위(2)는 9/14 배정인데 완료 조건이 이슈에 없었다. 이빌드가 착수 직전(9/21)에 재요청, 지시서는 9/22 확정 — 배정 대비 8일 지연.
- 막혔나: 사규 3조의 "되돌린다"에 창구·마감이 없다. 배정표 이식 때 담당·상태만 옮겨지고 3항목 검증이 빠졌고, '검증 대기' 절은 하류(제출→판정)만 잡고 상류(배정→지시서)는 비어 있다.
- 바꾸면: 배정표에 '완료 조건 위치' 열 추가, 결측 행은 `지시서 대기` 마커 → 종합자가 매일 블로커로 게시. 결측 발견이 착수 시점에서 배정 익일로 앞당겨진다.

마찰 3의 열 추가와 마찰 1의 절 신설은 배정표 관리 권한(ADR 0006) 내라 자체 시행 가능하다. 종합 판정이 필요한 것(현황 블록 교체, ADR 신규 작성)은 보고서에 상정 문서로 명시했다.
